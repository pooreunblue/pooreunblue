# 안녕하세요! 끊임없이 성장하는 백엔드 개발자 백승호입니다.

명지대학교 정보통신공학과 졸업을 앞두고 있으며, 안정적이고 확장 가능한 서버 아키텍처를 설계하는 것에 관심이 많습니다. 
Java와 Spring 생태계를 주로 다루며, 필요에 따라 Python과 Django를 활용한 유연한 개발도 가능합니다.
단순한 기능 구현을 넘어 클린 코드와 객체 지향적인 설계를 지향하고, 자동화된 배포 파이프라인 구축을 통해 효율적인 시스템 운영을 고민합니다.

- 🎓 **명지대학교 정보통신공학과** 졸업 예정
- 🌱 대용량 트래픽 처리와 쿼리 최적화, 인프라 자동화에 대해 꾸준히 학습하고 있습니다.
- 💬 새로운 기술과 도메인에 관한 논의를 언제나 환영합니다!
